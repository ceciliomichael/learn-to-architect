# Module 09 Quiz

1. Which join returns all records from the right table and matched records from the left table?
   - A) `LEFT JOIN`
   - B) `RIGHT JOIN`
   - C) `INNER JOIN`
   - D) `CROSS JOIN`

2. What pattern is used to identify rows in Table A that have no matching records in Table B?
   - A) `LEFT JOIN ... WHERE B.key IS NULL`
   - B) `INNER JOIN ... WHERE B.key IS NULL`
   - C) `CROSS JOIN ... WHERE A.key = B.key`
   - D) `RIGHT JOIN ... WHERE A.key IS NOT NULL`
