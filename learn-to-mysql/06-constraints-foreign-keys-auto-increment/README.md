# Module 06: Protect Data with Constraints and `AUTO_INCREMENT`

## What You Will Learn

In this module, you will learn how MySQL manages auto-incrementing primary keys (`AUTO_INCREMENT`), enforces relational foreign keys with InnoDB, configures `ON DELETE CASCADE` and `ON UPDATE RESTRICT`, and checks constraint validity.

---

## `AUTO_INCREMENT` in MySQL

In MySQL, integer surrogate primary keys use the `AUTO_INCREMENT` attribute:

```sql
CREATE TABLE `departments` (
  `dept_id` INT AUTO_INCREMENT PRIMARY KEY,
  `name` VARCHAR(50) NOT NULL UNIQUE
) ENGINE=InnoDB;
```

To fetch the auto-generated primary key ID generated by your last `INSERT` statement in MySQL, use `LAST_INSERT_ID()`:

```sql
SELECT LAST_INSERT_ID();
```

---

## Foreign Key Constraints (InnoDB)

Unlike SQLite (which requires a PRAGMA to turn on foreign keys), MySQL's default **InnoDB storage engine enforces foreign key constraints automatically**:

```sql
CREATE TABLE `employees` (
  `emp_id` INT AUTO_INCREMENT PRIMARY KEY,
  `name` VARCHAR(100) NOT NULL,
  `dept_id` INT NOT NULL,
  CONSTRAINT `fk_emp_dept` 
    FOREIGN KEY (`dept_id`) 
    REFERENCES `departments`(`dept_id`) 
    ON DELETE CASCADE 
    ON UPDATE CASCADE
) ENGINE=InnoDB;
```
