# Exercises: Module 04

Work locally. Predict before compiling or running.

## 1. Trace

For integer 7, predict 7 / 2, 7 % 2, and the Boolean result of 7 > 3 && 7 < 10.

## 2. Repair

Assign an i32 directly to an f64, observe the error, and repair it explicitly.

## 3. Modify

Report whether the input integer is negative, zero, or positive as well as even or odd.

## 4. Build

Build a Celsius-to-Fahrenheit converter that reads text, parses f64, computes the result, and handles invalid input without crashing.

When finished, run cargo fmt, cargo clippy, and cargo check. Understand warnings before changing code only to silence them.
