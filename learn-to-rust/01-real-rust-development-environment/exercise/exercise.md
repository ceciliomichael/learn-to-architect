# Exercises: Module 01

Do these in a local Cargo project. Predict first, then compile or run.

## 1. Trace

After `cargo new hello --edition 2024`, which files belong to your source and project configuration, and which directory is generated by builds?

Write down your prediction before running the code.

## 2. Repair

Create a project, remove one closing parenthesis from `println!("hello");`, run `cargo check`, and repair the syntax.

Use the compiler diagnostic, but explain the rule in your own words before editing.

## 3. Modify

Change the starter program to print your name on one line and `Learning Rust locally` on the next.

Run `cargo fmt` and `cargo clippy` after the change.

## 4. Build

Create a fresh project named `toolchain_report`. Make it print three labels: `Compiler`, `Build tool`, and `Edition`. The values can be descriptive text rather than automatically detected versions.

### Completion standard

Your program should compile without warnings you understand, behave correctly for the requested cases, and remain simple enough that you can explain every line.
