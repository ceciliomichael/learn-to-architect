# Quiz Answers: Module 01

## 1

Source code is human-written input. An executable is machine-runnable output produced from source and its dependencies.

## 2

`rustc` compiles Rust. Cargo coordinates packages, builds, dependencies, tests, run commands, profiles, and other project tasks.

## 3

`target/` is generated build output. Cargo can replace it, so it is not a stable place for source.

## 4

Start with the first relevant primary error. One syntax error can make later text impossible to parse and create secondary diagnostics.

## 5

No. A code editor is useful, but the required workflow is terminal plus the Rust toolchain. This keeps the development process understandable and editor-independent.
