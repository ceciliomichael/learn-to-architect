# Exercises: Module 22

Work locally and explain your choices.

## 1. Trace

Does iter().map(...) alone guarantee every mapping closure runs? Explain.

## 2. Repair

Create a map pipeline with no consumer, then add collect, sum, count, or a loop.

## 3. Modify

Filter even integers, square them, and sum them without an intermediate Vec.

## 4. Build

Given lines of text, trim them, discard empty lines, turn the rest into owned Strings, and collect. Also write the equivalent loop.

Finish with cargo fmt, cargo clippy, cargo test when tests exist, and cargo check.
