# Exercises: Module 19

Work locally and explain your choices.

## 1. Trace

Can Pair<T> hold an i32 in first and a String in second under its current definition?

## 2. Repair

Attempt a generic function that debug-prints T. Identify the missing capability without adding unrelated bounds.

## 3. Modify

Define Pair<A,B> with borrowed getters so the fields may have different types.

## 4. Build

Create a generic Stack<T> backed by Vec<T> with push, pop, len, and is_empty.

Finish with cargo fmt, cargo clippy, cargo test when tests exist, and cargo check.
