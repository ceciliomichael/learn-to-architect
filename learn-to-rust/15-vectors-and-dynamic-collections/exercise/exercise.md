# Exercises: Module 15

Work locally and explain your choices.

## 1. Trace

After let mut v = vec![1,2]; v.push(3); v.pop();, what is the final content?

## 2. Repair

Consume a vector in a for loop and then try to use it. Repair by borrowing during iteration.

## 3. Modify

Store five scores, add 5 to each through mutable iteration, then print scores at least 80.

## 4. Build

Build a tiny task list using Vec<String> with add, list, and checked remove-by-index functions.

Finish with cargo fmt, cargo clippy, cargo test when tests exist, and cargo check.
