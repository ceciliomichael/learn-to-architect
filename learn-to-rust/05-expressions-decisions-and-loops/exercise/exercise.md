# Exercises: Module 05

Work locally. Predict before compiling or running.

## 1. Trace

Predict the values printed by for n in 0..3.

## 2. Repair

Create an if expression whose branches produce integer 10 and string ten. Repair it by choosing one meaningful result type.

## 3. Modify

Extend the grade example with D for 60 through 69 and F below 60.

## 4. Build

Build a number-guessing loop with a fixed secret. Read integers until a guess matches, report low/high/correct, and continue after invalid numeric input.

When finished, run cargo fmt, cargo clippy, and cargo check. Understand warnings before changing code only to silence them.
