# Exercises: Module 06

Work locally. Predict before compiling or running.

## 1. Trace

For fn square(n: i32) -> i32 { n * n }, identify the parameter, return type, and returned expression.

## 2. Repair

Add a semicolon after a final expression in a function returning i32, observe the mismatch, and repair it.

## 3. Modify

Add describe(width, height) that calls area and is_large and prints a summary.

## 4. Build

Build a shipping-cost calculator with one function for base cost, one for surcharge logic, and main for coordination.

When finished, run cargo fmt, cargo clippy, and cargo check. Understand warnings before changing code only to silence them.
