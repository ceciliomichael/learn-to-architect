# Exercises: Module 07

Use a local Cargo project. Predict first.

## 1. Trace

For let pair = ("north", 4); identify the type roles of position 0 and position 1 and show one destructuring pattern.

## 2. Repair

Index a three-element array with 3, observe the panic, then replace direct indexing with get and handle absence.

## 3. Modify

Compute the sum of a fixed array of four integers using a loop rather than four handwritten additions.

## 4. Build

Create a weekly_temperature program using a seven-element array. Print every reading, the count, and whether a user-chosen index exists.

Finish with cargo fmt, cargo clippy, and cargo check.
