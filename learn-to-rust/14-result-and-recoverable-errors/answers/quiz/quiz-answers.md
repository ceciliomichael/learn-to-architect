# Quiz Answers: Module 14

## 1

Option represents presence or absence without a failure reason; Result represents success or failure with error information.

## 2

It returns early from the current function with a compatible error.

## 3

The caller often has more context about whether to retry, report, transform, or ignore the failure. Printing inside a library also couples it to one presentation policy.

## 4

When an invariant the program relies on is violated and meaningful recovery is not part of the contract, rather than for normal external failures.

## 5

Context identifies which operation or domain input failed, making diagnosis and user reporting more useful.
