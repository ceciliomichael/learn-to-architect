# Exercises: Module 02

Work locally. Predict before compiling or running.

## 1. Trace

Put cargo check, cargo build, and cargo run in conceptual order and state what each adds.

## 2. Repair

Write two println statements and intentionally omit the semicolon between them. Repair the program from the diagnostic.

## 3. Modify

Make the example print Source, Compile, Executable, and Process on four lines.

## 4. Build

Create a project named compile_story and print a five-line explanation of what happens between editing src/main.rs and seeing output.

When finished, run cargo fmt, cargo clippy, and cargo check. Understand warnings before changing code only to silence them.
