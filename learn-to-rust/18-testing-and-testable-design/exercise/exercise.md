# Exercises: Module 18

Work locally and explain your choices.

## 1. Trace

Why does a test with only println normally pass?

## 2. Repair

Turn a print-only test into an assertion.

## 3. Modify

Add a test documenting the function's behavior with negative numbers.

## 4. Build

Create a library with subtotal, discount, and final_total plus normal, boundary, invalid, and integration tests.

Finish with cargo fmt, cargo clippy, cargo test when tests exist, and cargo check.
