# Exercises: Module 17

Work locally and explain your choices.

## 1. Trace

In a package with both src/lib.rs and src/main.rs, what crate roots exist?

## 2. Repair

Expose a struct but keep a field private, then add a public constructor instead of exposing the field.

## 3. Modify

Add a private helper module used by report but unavailable to external callers.

## 4. Build

Create an invoice library with customer and invoice modules and a narrow public API.

Finish with cargo fmt, cargo clippy, cargo test when tests exist, and cargo check.
