# Exercises: Module 03

Work locally. Predict before compiling or running.

## 1. Trace

Predict the output of: let x = 5; let x = x + 1; println!("{x}"); Is this mutation?

## 2. Repair

Create let score = 10; and then assign score = 11;. Repair it in two semantically different ways.

## 3. Modify

Add a mutable remaining counter initialized from a constant and decrement it once.

## 4. Build

Build profile_card that stores and prints a name, age, height, active flag, and one-letter group code using appropriate values.

When finished, run cargo fmt, cargo clippy, and cargo check. Understand warnings before changing code only to silence them.
