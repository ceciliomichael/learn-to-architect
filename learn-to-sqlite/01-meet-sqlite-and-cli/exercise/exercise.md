# Module 01 Exercise: Getting Started with SQLite CLI

## Instructions

1. Open your terminal and create a new practice directory named `sqlite_mod01_practice`.
2. Launch `sqlite3` and attach to a new database file named `test_db.sqlite`.
3. Enable headers with `.headers on` and set output mode to `.mode box`.
4. Run a query that returns two columns:
   - Column 1 aliased as `course_name` with string value `'Learn SQLite'`
   - Column 2 aliased as `module_number` with numeric value `1`
5. Use dot-commands to verify your open database file and exit the CLI.
